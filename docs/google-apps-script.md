# Google Apps Script Web App Integration Architecture

This document describes the serverless backend architecture using Google Apps Script and Google Sheets for the **AI Loan Eligibility Checker** (FINAI) application.

---

## 1. Overview & Security Approach

The frontend client application is a 100% static web application (HTML5/CSS3/Vanilla JS) hosted on GitHub Pages or any static web host. To securely interact with persistent storage and AI services:

- **No Secrets in Frontend:** Claude API keys and Google service credentials are never placed in frontend code.
- **Serverless Gateway:** Google Apps Script acts as an intermediary (proxy) Web App endpoint that receives structured POST requests, appends records to Google Sheets, and communicates server-side with the Claude API.

## 3. Data Storage: Google Sheets Schema

When an applicant completes the Loan Eligibility check, the record is logged into a connected Google Sheet.

### Target Columns (Row Structure):

| Column # | Header Name | Description | Example |
|---|---|---|---|
| **A** | Timestamp | ISO 8601 or formatted UTC timestamp | 2026-09-25 16:30:00 |
| **B** | Name | Applicant Full Name | Test User |
| **C** | Salary | Monthly salary in INR | 50000 |
| **D** | Credit Score | Credit score (300–900) | 750 |
| **E** | Existing EMI | Existing monthly debt obligations in INR | 10000 |
| **F** | Age | Applicant age in years | 25 |
| **G** | Result | Decision status (Approved / Rejected) | Approved |
| **H** | Eligible Loan Amount | Maximum eligible loan capacity in INR | 1000000 |

## 5. Google Apps Script Implementation Reference (Code.gs)

Below is the planned server-side script to be deployed as a Web App with access set to *Anyone*:

`javascript
/**
 * Google Apps Script Web App - AI Loan Eligibility Gateway
 */

const SHEET_ID = YOUR_SPREADSHEET_ID;
const CLAUDE_API_KEY = YOUR_CLAUDE_API_KEY; // Configured securely inside Apps Script Script Properties

function doPost(e) {
  try {
    const contents = JSON.parse(e.postData.contents);
    const type = contents.type;

    if (type === eligibility) {
      return handleSaveEligibility(contents);
    } else if (type === ai_guidance) {
      return handleAIGuidance(contents.data);
    } else {
      return createJsonResponse({ success: false, message: Invalid request type });
    }
  } catch (error) {
    return createJsonResponse({ success: false, message: error.toString() });
  }
}

function handleSaveEligibility(data) {
  const sheet = SpreadsheetApp.openById(SHEET_ID).getActiveSheet();
  const timestamp = new Date();
  
  sheet.appendRow([
    timestamp,
    data.name || Anonymous,
    data.salary || 0,
    data.creditScore || 0,
    data.existingEmi || 0,
    data.age || 0,
    data.result || N/A,
    data.eligibleLoanAmount || 0
  ]);

  return createJsonResponse({
    success: true,
    message: Record saved successfully
  });
}
